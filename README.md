# Studio Spaces — clean-room recreation

A responsive React/Vite interior-design portfolio inspired by the editorial structure and visual rhythm of wee-spaces.com. This package does **not** contain that website's proprietary source code, logo, text, photography, or backend.

## Included

- Home, About, Projects, Project Detail, Media and Contact pages
- Responsive desktop/mobile navigation
- Editorial typography and asymmetrical project grids
- Reusable React components and project data
- Demo contact form interaction
- Free demonstration imagery loaded from Unsplash

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customise

- Edit project names and image URLs in `src/data.js`
- Update colours and typography variables at the top of `src/styles.css`
- Replace studio name, email addresses and social links in the page/component files
- Connect the contact form to Formspree, Web3Forms, a serverless function or your own API

## Important

Use your own licensed photography, logo and copy before publishing. Unsplash images are for demonstration and remain subject to Unsplash's licence and attribution guidance.
